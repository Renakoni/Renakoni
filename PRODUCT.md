# Product

## Register

brand

## Users

GitHub visitors, fellow students, and open-source peers encountering Renakoni's profile. The page is a personal playground, not a recruiting surface.

## Product Purpose

Turn live GitHub activity into a small, self-updating digital toy that expresses a curious student developer's personality without exposing a real name or contact details.

## Brand Personality

Playful, mechanical, curious. Geeky without becoming a terminal costume; polished without becoming corporate.

## Anti-references

Resume-style portfolios, long biographies, project screenshot galleries, badge walls, skill-icon grids, generic cyberpunk neon, and stacked stat cards.

## Design Principles

1. One memorable toy carries the page.
2. Live data is creative material, not proof of productivity.
3. Keep copy short and let GitHub's pinned repositories explain the work.
4. Customize familiar profile widgets until they feel specific to Renakoni.

## Accessibility & Inclusion

Support GitHub light and dark themes, preserve readable contrast, provide useful alternative text, and respect reduced-motion preferences for decorative animation.
